## 1. Candidate Shot Evaluation Architecture

Candidate shots generated by `GraphicsEngine_ScanAndExecuteBestShot` are evaluated across three distinct tiers:

* **Tier 1 (Direct Clean Pot):** Striker directly impacts target puck with 0 cushion rebounds; target puck travels directly into pocket with 0 cushion bounces.
* **Tier 2 (1-Cushion Bank Pot):** Striker directly hits target puck; target puck reflects off exactly 1 cushion before pocketing.
* **Tier 3 (Combination Pot):** Striker impacts Puck A, which then impacts Puck B into a pocket (0 cushion bounces for both).

## 2. Target Puck Color Modes

| Mode | Identifier | Permitted Targets | Use Case |
| :--- | :--- | :--- | :--- |
| **AUTO** | `0` | Assigned player color (White or Black) + Queen (3) | Standard Carrom matches with automatic detection |
| **WHITE ONLY** | `1` | White pucks (1) + Queen (3) | Player assigned White in Classic Carrom |
| **BLACK ONLY** | `2` | Black pucks (2) + Queen (3) | Player assigned Black in Classic Carrom |
| **ANY COIN** | `3` | White (1), Black (2), Queen (3) | Disc Pool, Freestyle, Carrom Points matches |

## 3. Foul / Scratch Protection

* **Previous Behavior:** Striker entering a pocket was marked as `pocketPotted = true`, lighting the pocket green and scoring the foul as a successful pot.
* **Repaired Invariant:**
  - `sim.strikerInPocket` marks `pocketScratched = true` (Crimson Warning Red `#FF2222`).
  - Striker guideline turns warning red.
  - `evaluateCandidateShot` explicitly rejects scratch shots with score $-\infty$.

---

## 4. Visual Rendering Hygiene

* **Hairline Guideline:** Default thickness set to $0.20\text{ cm}$ (crisp and razor-thin, replacing the previous $0.60\text{ cm}$ thick band).
* **Unobstructed Coins:** Removed all solid filled circles over passive coins. Only the single target coin receives a subtle outer wireframe ring.
* **Clean Pockets:** Removed opaque $1.0\text{ alpha}$ solid green discs covering pocket holes. Replaced with delicate $0.35\text{ alpha}$ guidance rings.
